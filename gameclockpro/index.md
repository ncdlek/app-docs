## Six time controls

| Time control | How it works | Typical use |
|---|---|---|
| **Japanese byo-yomi** | Main time, then a number of periods of fixed length. Move within a period and it resets; let it expire and you use up a period. | Go, shogi |
| **Canadian byo-yomi** | Main time, then an overtime block in which you must play a set number of stones or moves. | Go |
| **Fischer** | A fixed increment is added after every move, with an optional maximum. | Chess blitz and rapid |
| **Bronstein** | After each move you get back the time you used, up to the delay. | Chess |
| **Delay** | Each turn a short delay counts down before your main time starts. | Chess (US delay) |
| **Absolute** | One block of time; when it runs out, you lose. | Sudden death, casual games |
